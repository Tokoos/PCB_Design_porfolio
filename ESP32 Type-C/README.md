# 🔌 ESP32 Type-C — Carte de développement

Carte de développement basée sur le microcontrôleur **ESP32**, équipée d'un port **USB Type-C** pour une alimentation et une programmation rapides et pratiques.

## 📋 Description

L'ESP32 Type-C intègre le **Wi-Fi** et le **Bluetooth**, permettant de créer facilement des projets connectés tels que :
- 🔐 Systèmes de sécurité
- 🏠 Domotique
- 📡 Surveillance
- 🌐 Objets intelligents (IoT)

Grâce à sa puissance, sa faible consommation d'énergie et ses nombreuses entrées/sorties, cette carte est idéale pour développer des solutions IoT modernes, fiables et économiques.

## ✨ Caractéristiques

| Caractéristique | Détail |
|---|---|
| Microcontrôleur | ESP32 |
| Connectivité sans fil | Wi-Fi + Bluetooth |
| Alimentation / Programmation | USB Type-C |
| Consommation | Faible |
| E/S | Nombreuses entrées/sorties disponibles |
