# 🧭 Carte électronique d'interfaçage CAN/UART

Carte électronique conçue dans le cadre de mon expérience professionnelle.

## 📋 Description

Cette carte assure l'acquisition et le traitement de données via les interfaces **CAN** et **UART**, permettant son intégration dans des systèmes industriels nécessitant une communication fiable avec d'autres équipements ou modules.

## 🛠️ Matériel utilisé

| Composant | Rôle |
|---|---|
| **Microcontrôleur** | Traitement des données et gestion des communications |

## 🔗 Communications utilisées

| Protocole | Usage |
|---|---|
| **CAN** | Communication avec d'autres équipements industriels (bus terrain) |
| **UART** | Communication série avec périphériques / modules |

## ⚙️ Fonctionnement

1. Acquisition des données via les interfaces disponibles
2. Traitement embarqué des informations
3. Transmission des données via **CAN** et/ou **UART** vers les autres équipements du système

## ✨ Points forts

- 🔗 Double interface de communication (CAN + UART) pour une intégration flexible
- 🏭 Conçue pour environnements industriels
- ⚙️ Architecture compacte en 2 couches

## 🖥️ Conception électronique

Toute la conception matérielle (schémas et routage) a été réalisée sur **Altium Designer**.

### 🧩 Caractéristiques du PCB

| Caractéristique | Détail |
|---|---|
| Nombre de couches | 2 couches |
| Documentation de production | BOM, plan d'assemblage, fichiers Gerber |

## 🚀 Applications possibles

- Intégration dans des systèmes de bus CAN industriels
- Interfaçage avec équipements de mesure et de contrôle
- Solutions embarquées pour environnements industriels
